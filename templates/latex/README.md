# LaTeX Resume Template Backups

These repositories are shallow clones kept as reference/backup templates. The application currently uses its controlled templates under `src/career_resume_skill/templates/`; these backups are not automatically injected into generated documents.

| Local directory | Source repository | Typical use |
| --- | --- | --- |
| `jakegut-resume` | https://github.com/jakegut/resume | One-page software/engineering resume |
| `awesome-cv` | https://github.com/posquit0/Awesome-CV | General professional CV with rich sections |
| `billryan-resume` | https://github.com/billryan/resume | Chinese-friendly resume style |
| `awesome-resume-for-chinese` | https://github.com/dyweb/awesome-resume-for-chinese | Chinese resume template collection/reference |
| `financecv` | https://github.com/ArtemySazonov/financecv | Finance and IT applications |
| `sb2nov-resume` | https://github.com/sb2nov/resume | Compact software developer resume |
| `cv-latex-template` | https://github.com/matteocourthoud/cv-latex-template | One-page academic/professional CV |
| `academic-resume` | https://github.com/abrandenberger/academic-resume | Academic and research CV |
| `yaac-another-awesome-cv` | https://github.com/darwiin/yaac-another-awesome-cv | Font Awesome / Source Font CV |
| `altacv` | https://github.com/liantze/AltaCV | Modern alternative CV layout |

The original repository licenses and notices remain inside each cloned directory. Review a template's license before redistributing or publishing a derived template.

The duplicate `posquit0/Awesome-CV` entry in the source list was intentionally cloned once.
